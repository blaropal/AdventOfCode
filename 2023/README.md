# Advent of Code 2023

My solutions for the [Advent of Code](https://adventofcode.com/2023) puzzles for 2023.
This year I decided to implement the solutions in Python.

## Structure
Each day has its own folder, with the day number as its name, the solution code for a specific day is placed in a file called `solution.py` in its respective day folder. 

I also have a file in each folder called `input.txt` which contains my input for the puzzles.
Feel free to clone and replace with your input for the puzzles.

## Running the programs
Running the code is a simple as `python solution.go`.
